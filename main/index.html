Little X 2.0

The brain section from the deck, grounded in the real runtime.

Recent project notes show a working local Web UI, audited chat flow, provider/model catalog, and an experimental NVIDIA NIM path. The public site names those capabilities without implying the private runtime is exposed online.

Runtime

Local FastAPI Web UI

Implemented with GET /, GET /api/status, and POST /api/chat, reusing the agent runtime and persisting user/assistant messages in SQLite.

Models

Provider and model routing

Central catalog, aliases, local defaults, explicit fallback, CLI model commands, and UI controls for provider/model selection.

Experimental

NVIDIA NIM adapter

Integrated as an experimental/test provider with env-only secrets, limited retry, rate-limit documentation, and fallback to local behavior when unavailable.
