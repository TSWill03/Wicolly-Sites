# Arquitetura de informação

## Princípio

A Home orienta; páginas internas explicam. Nenhum item principal depende de uma âncora `/#...`.

| Necessidade | Destino canônico |
| --- | --- |
| Entender quem é Wícolly | `/sobre/` |
| Encontrar projetos e estados | `/projetos/` |
| Usar o Veredra | `/veredra/` e `/projetos/veredra/` |
| Contratar tecnologia | `/servicos/` |
| Solicitar impressão 3D | `/blacklight3d/` |
| Entender o laboratório de servidores | `/infraestrutura/` |
| Escolher um canal | `/contato/` |
| Acompanhar atualizações | `/novidades/` |

O mapa do ecossistema na Home usa azul para software/serviços, violeta para IA, laranja para fabricação e neutros para infraestrutura. Verde aparece somente para um estado verificado.

`/portfolio/` permanece um alias editorial do índice estático de projetos. `/impressoes-3d/` continua redirecionando para `/blacklight3d/`.
